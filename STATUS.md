# Swaggy Studio — Status Summary

_Last updated: May 5, 2026_

## TL;DR

A 5-tool social-media manager built on Next.js 14 + Supabase + Anthropic. Auth, credits, and the **Caption** tool are wired end-to-end with real AI. **Image** and **Ads** tools share the same intent-driven UX but currently produce placeholder output (no real image-gen API integrated yet). Marketplace and connections scaffolding exists but is not user-facing yet.

---

## What's Built and Working

### Foundation
- **Next.js 14.2 App Router**, React 18, TypeScript strict, Tailwind.
- **Supabase**: schema applied, RLS in place, anon + service-role keys wired via `.env.local`.
- **Auth**: real email/password sign-up + sign-in (`/login`, `/signup`) using `supabase.auth`. Dev bypass disabled.
- **Middleware**: session refresh + protected-route redirects.
- **Observability**: structured server logs (`request_id`, `user_id`, `route`, `latency_ms`, `outcome`).
- **Security**: same-origin CSRF checks, HMAC-signed OAuth state.

### Credits
- Model-aware cost matrix in `lib/credits/costs.ts`.
- `spendOrFail` / `refund` helpers with timeouts — **no silent fallbacks**: any Supabase outage returns honest 503, any insufficient balance returns 402.
- `/api/credits/balance` endpoint live.
- Account settings page (`/settings/account`) shows real balance, plan flag, member-since.

### Caption Tool (`/tools/caption`) — fully working
- Guided "AI Co-Pilot" UX:
  - Card layout: Intent → Creative Direction → AI Power → Photo
  - Pill-row segmented controls for Goal, Tone, Emotion, Hook Style
  - Smart guidance banner (suggests Tone/Emotion/Hook based on Goal)
  - AI Power tier picker (Fast / Balanced / Pro) with advanced model dropdown
  - Sticky CTA showing cost + balance
- Single-call multi-variant generation via Claude (Haiku or Sonnet).
- Each variant comes back with `caption`, `hook_type`, `tone`, `reasoning`, and a 1–100 `score` against the user's goal.
- API also returns `best_index` + `best_reason` → "Joestar's Pick" banner.
- Variants sorted: pick first, then by score descending. % match badges color-coded.
- Animated loading screen (orb + rotating stage messages + shimmer skeletons).
- Editor step: edit caption, then preview. Preview persists to session storage.

### Image Tool (`/tools/image`) — UX complete, output is placeholder
- Same intent-card UX as caption tool:
  - Description + Audience + Aspect ratio + Goal + Style + Mood
  - "Also write a caption for the chosen image" toggle (on by default)
- Animated loading screen with skeleton tiles.
- 4 variants rendered as styled gradient placeholders, scored locally (1–100), sorted, with Joestar's Pick.
- **Caption sub-flow**: after picking an image, second form prompts for caption brief + tone, then calls `/api/tools/caption` for a real Claude-generated caption.
- Final "Ready to post" screen shows image + caption with copy button.

### Ads / Campaign Tool (`/tools/campaign`) — UX complete, output is heuristic
- Same intent-card UX:
  - Brief + Audience + Channel + Goal + Tone + Budget feel
- 3 strategies (Safe / Engagement / Bold) generated by local heuristics, scored against goal+budget combo, sorted with Joestar's Pick.
- Animated loading screen.
- Picked strategy view + save toast.

### Marketplace Scaffolding
- `lib/features.ts` feature flags, `lib/marketplace/types.ts`, profile helpers.
- `/onboarding/role/[role]` page with role toggle and profile forms (layout fixed for no-sidebar shell).
- API routes under `/api/marketplace/*`.

### AI Framework
- `lib/ai/{system,client,behavioral,prompts,schemas}` modules in place.
- `ModelPicker` and `IntentFields` components shared by tools.
- System prompt explicitly prevents Claude from echoing the user's brief.

## What Doesn't Work / Not Real Yet

| Area | Status | Why |
|---|---|---|
| **Image generation** | Placeholder gradients | No image-gen provider (DALL·E / SDXL / Imagen) wired up. UX is final; only the model call is missing. |
| **Ads strategy generation** | Local heuristics | No LLM call yet. Strategies are deterministic templates. Scoring is rule-based, not learned. |
| **Caption "Balanced" tier** | Disabled | `modelId: null` in `ModelPicker`. Only Fast (Haiku) and Pro (Sonnet) are active. |
| **OpenAI / Gemini models** | Marked `active: false` in cost matrix | Not implemented; only Anthropic SDK is wired. |
| **Marketplace UI** | Scaffolded, not surfaced | Behind feature flag, no entry points in nav yet. |
| **Connections / posting** | API + page exist | No real OAuth providers connected; can't actually publish to FB/IG/TikTok. |
| **Credit top-up / billing** | Not built | No Stripe integration; balance can only be modified in DB. |
| **Saved drafts / history** | Not surfaced | Schema supports it but no list/library UI. |
| **Image → caption "credits" math** | UI claims +1 credit | The caption sub-call charges separately via `/api/tools/caption`; no combined transaction. |

## Known Friction

- **Stale browser cache** after dev rebuilds — hard refresh (Ctrl+Shift+R) needed occasionally.
- **Stale `.next` cache** after large refactors — `rm -rf .next` + restart fixes it.
- **Supabase URL must resolve** — if DNS fails, all DB-touching routes return 503 (intentional, no silent fallback).
- **Service-role key** must be the JWT starting with `eyJ`, not the anon key or REST URL.
